Tips & trik Blasenote

Panduan singkat agar pencatatan lebih cepat dan konsisten.

Input nominal cepat
Ketik 10 untuk Rp10.000 atau 10.500 untuk Rp10.500. Angka diformat saat kamu keluar dari kolom nominal.
Rp
Pilih kategori yang sesuai
Gunakan kategori seperti Makanan, Bensin, Tagihan, atau Hiburan agar laporan pengeluaran lebih akurat.
▦
Transaksi berulang
Aktifkan pilihan berulang terlebih dahulu untuk memilih frekuensi mingguan, bulanan, atau tahunan. Saat ini fitur ini hanya menyimpan penanda pada transaksi, belum membuat jadwal otomatis terpisah. Edit/hapus hanya memengaruhi transaksi yang dipilih.
↻
Saldo dan transfer
Periksa dompet yang dipilih sebelum menyimpan transaksi. Transfer antar-dompet masih perlu penyempurnaan sebelum dipakai sebagai pembukuan final.
▣

Panduan Supabase

  1. Buat proyek baru di supabase.com.
  2. Buka SQL Editor dan jalankan isi file schema.sql yang disertakan.
  3. Di Authentication → Providers, aktifkan Email. Atur Site URL dan Redirect URLs untuk domain GitHub Pages.
  4. Salin Project URL dan anon/publishable key ke kolom di atas.
  5. Daftar akun. Jika konfirmasi email aktif, verifikasi email sebelum masuk.
  6. Deploy index.html melalui GitHub Pages. File SQL tidak perlu dipublikasikan ke situs.
